# General Aptitude: formulae

Revision sheet. Explanations and examples are in the [notes](#/subjects/ga/notes).

## Arithmetic

| Quantity | Formula |
|---|---|
| Percentage change | $\frac{\text{new} - \text{old}}{\text{old}} \times 100$ |
| Successive changes $a\%$, $b\%$ | $a + b + \frac{ab}{100}$ |
| Simple interest | $\frac{Prt}{100}$ |
| Compound amount | $P\left(1 + \frac{r}{100}\right)^n$ |
| Alligation | $(c_2 - m) : (m - c_1)$ |
| Work together | $\frac{ab}{a+b}$ days |
| Average speed (equal distances) | $\frac{2xy}{x+y}$ |
| Relative speed | same direction $\lvert u-v \rvert$, opposite $u+v$ |
| Profit % | $\frac{SP - CP}{CP} \times 100$ |

## Powers, logs, series

| Quantity | Formula |
|---|---|
| Change of base | $\log_b a = \frac{\log a}{\log b}$ |
| Product / power | $\log ab = \log a + \log b$; $\log a^n = n\log a$ |
| AP sum | $\frac n2(2a + (n-1)d)$ |
| GP sum | $a\frac{r^n - 1}{r - 1}$; infinite $\frac{a}{1-r}$ |
| $1 + 2 + \dots + n$ | $\frac{n(n+1)}{2}$ |
| $1^2 + \dots + n^2$ | $\frac{n(n+1)(2n+1)}{6}$ |
| Unit-digit cycles | 2: 2,4,8,6 · 3: 3,9,7,1 · 7: 7,9,3,1 · 8: 8,4,2,6 |

## Counting and probability

| Quantity | Formula |
|---|---|
| Arrangements | $n!$; circular $(n-1)!$ |
| Selections | $\binom nr$ |
| At least one | $1 - P(\text{none})$ |

## Geometry

| Quantity | Formula |
|---|---|
| Heron | $\sqrt{s(s-a)(s-b)(s-c)}$ |
| Equilateral triangle | $\frac{\sqrt3}{4}a^2$ |
| Sector | $\frac{\theta}{360}\pi r^2$ |
| Cone volume | $\frac13\pi r^2h$ |
| Sphere | $\frac43\pi r^3$, $4\pi r^2$ |
| Cylinder | $\pi r^2 h$, $2\pi rh$ |
| Regular $n$-gon interior angle | $\frac{(n-2)180}{n}$ degrees |
| Diagonals | $\frac{n(n-3)}{2}$ |
| Scaling by $k$ | area $k^2$, volume $k^3$ |

## Reasoning

| Quantity | Formula |
|---|---|
| Clock-hand angle | $\lvert 30H - 5.5M \rvert$ |
| Odd days | normal year 1, leap year 2 |
| Pie chart | $1\% = 3.6^\circ$ |
| Painted cube faces 3 / 2 / 1 / 0 | $8$ / $12(n-2)$ / $6(n-2)^2$ / $(n-2)^3$ |
| Punch after $k$ folds | $2^k$ holes |
