# Books & resources

You do not need many sources. One standard book per subject (for depth when the notes here are not enough), the official papers, and one place to discuss PYQ solutions is plenty.

## Official sources

| Resource | Use it for |
|---|---|
| [GATE 2027 official site (IIT Madras)](https://gate2027.iitm.ac.in/) | Dates, admit card, syllabus, official papers and answer keys, virtual calculator |
| Past official papers and keys | See [Past papers & answer keys](#/papers) on this site |

## Standard books, by subject

| Subject | Standard text | Read selectively |
|---|---|---|
| Discrete Mathematics | Kenneth Rosen, *Discrete Mathematics and Its Applications* | Logic, relations, graphs, counting, recurrences; skip number theory beyond basics |
| Linear Algebra | Gilbert Strang, *Introduction to Linear Algebra* | Rank, systems, eigenvalues, LU |
| Probability | Sheldon Ross, *A First Course in Probability* | Conditional probability, Bayes, standard distributions |
| Calculus | Any engineering-mathematics text (e.g. B. S. Grewal) | Limits, maxima/minima, mean value theorems, definite integrals |
| Digital Logic | M. Morris Mano, *Digital Design* | K-maps, Quine–McCluskey, combinational and sequential design, number systems |
| Computer Organization | Hamacher et al., *Computer Organization*; Patterson & Hennessy, *Computer Organization and Design* | Addressing modes, control unit, cache, pipelining |
| C Programming | Kernighan & Ritchie, *The C Programming Language* | Pointers, arrays, storage classes, recursion |
| Data Structures & Algorithms | Cormen et al., *Introduction to Algorithms* (CLRS) | Asymptotics, sorting, heaps, hashing, greedy, DP, graph algorithms |
| Theory of Computation | Peter Linz, *An Introduction to Formal Languages and Automata*; Michael Sipser, *Introduction to the Theory of Computation* | Linz for practice, Sipser for decidability |
| Compiler Design | Aho, Lam, Sethi & Ullman, *Compilers: Principles, Techniques, and Tools* | Parsing tables, SDT, intermediate code, data-flow analysis |
| Operating System | Silberschatz, Galvin & Gagne, *Operating System Concepts* | Synchronisation, deadlock, scheduling, paging and virtual memory |
| Databases | Silberschatz, Korth & Sudarshan, *Database System Concepts* | Relational algebra, SQL, normalisation, indexing, transactions |
| Computer Networks | Kurose & Ross, *Computer Networking: A Top-Down Approach*; Forouzan, *Data Communications and Networking* | Delay and throughput, MAC, routing, IPv4/CIDR, TCP |
| General Aptitude | Past GATE GA sections (all papers share the GA style) | Vocabulary, data interpretation, spatial puzzles |

## Free online material

| Resource | Subject |
|---|---|
| [NPTEL](https://nptel.ac.in/) | Lecture series by IIT faculty for every GATE CS subject; useful when a topic needs a full explanation |
| [Operating Systems: Three Easy Pieces](https://pages.cs.wisc.edu/~remzi/OSTEP/) | Free, readable OS book: concurrency, scheduling, virtual memory |
| [MIT OCW 18.06 Linear Algebra](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/) | Gilbert Strang's linear algebra lectures |
| [Database System Concepts companion site](https://db-book.com/) | Slides and practice for the standard DB text |
| [GATE Overflow](https://gateoverflow.in/) | Community-discussed solutions to past GATE CSE questions; check answers against the official key |

## How to use these

- Use this site's notes as your primary text and a standard book only when you need a deeper explanation or more practice.
- For PYQs, always trust the **official answer key** over any forum answer; where the key was revised, the revised key counts.
- Don't collect material. Finish one source per subject.
